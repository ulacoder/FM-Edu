---

## 🎯 Решаемая проблема

Качество образования в Казахстане сильно различается в зависимости от региона и школы. Ученики в малых городах не имеют доступа к качественным репетиторам, а учителя не успевают уделить внимание каждому индивидуально.

**EduAI.kz** — это масштабируемое AI-решение, которое:
- ✅ Персонализирует обучение под уровень каждого ученика
- ✅ Предоставляет доступ к качественным материалам независимо от региона
- ✅ Даёт мгновенную обратную связь через AI
- ✅ Помогает учителям отслеживать прогресс класса

---

## 🚀 Основные возможности

### Для учеников:
- **📊 Диагностика уровня знаний** — AI-тест определяет ваш уровень (начальный/средний/продвинутый)
- **🎯 Персонализированные рекомендации** — платформа подбирает темы и материалы под ваш уровень и цели
- **📺 Видео-материалы** — подборка YouTube видео по каждой теме
- **✍️ Практические задания** — AI генерирует задачи разного уровня сложности
- **💡 AI-обратная связь** — персонализированные объяснения к каждому ответу
- **📈 Отслеживание прогресса** — видите свои сильные и слабые стороны

### Для учителей:
- **👥 Мониторинг учеников** — статистика по всем ученикам в одном месте
- **📊 Аналитика прогресса** — средние баллы, активность, слабые места
- **➕ Добавление материалов** — возможность создавать свои задания
- **📈 Отчёты** — детальная информация по каждому ученику

## 📦 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone <ссылка-на-репозиторий>
cd eduai-kz
```

### 2. Установите зависимости
```bash
npm install
```

### 3. Настройте переменные окружения
Файл `.env.local` уже создан с API ключом Qwen. Проверьте его:
```env
DASHSCOPE_API_KEY=sk-ws-H.DMEYEYL.G3Ns...
QWEN_BASE_URL=https://ws-yf8sb129bygmh1i9...
JWT_SECRET=eduai_kz_secret_key_2026_hackathon
```

### 4. Инициализируйте базу данных
```bash
npx tsx lib/init-db.ts
```
Это создаст JSON файлы с темами по программе МОН РК (57 тем).

### 5. Запустите dev сервер
```bash
npm run dev
```

Откройте http://localhost:3000

## 🎓 Программа МОН РК

Платформа покрывает **7 предметов** для классов **7-12**:
- 📐 Математика
- ⚡ Физика
- 💻 Информатика
- 📊 Экономика
- 🧬 Биология
- ⚗️ Химия
- 🇬🇧 Английский язык

Все темы разбиты по **четвертям** и соответствуют школьной программе Казахстана.

## 🤖 Как работает AI-персонализация

### 1. Диагностика
Ученик проходит AI-генерированный тест из 10 вопросов разного уровня сложности.

### 2. Определение уровня
- **< 50%** → Начальный уровень
- **50-75%** → Средний уровень
- **> 75%** → Продвинутый уровень

### 3. Генерация рекомендаций
AI анализирует:
- Уровень знаний ученика
- Его цели (экзамены/олимпиады/повторение)
- Слабые места из диагностики

И подбирает **персонализированный план изучения тем**.

### 4. Адаптивные задания
Ученик может генерировать задания 3 уровней сложности:
- 🟢 **Легкий** — базовые задачи
- 🟡 **Средний** — стандартные задачи
- 🔴 **Сложный** — олимпиадные задачи

### 5. AI-обратная связь
На каждый неправильный ответ AI генерирует **персонализированное объяснение**, которое помогает понять ошибку.

## 💰 Монетизация (потенциальная)

### Freemium модель:
- **Бесплатно**: диагностика, базовые материалы, 5 заданий/день
- **Premium для учеников** (500 тг/месяц): неограниченные задания, AI-чат, приоритетная поддержка
- **B2B для школ** (50,000 тг/год за школу): дополнительная аналитика, интеграция с СЭО

### TAM/SAM/SOM:
- **TAM**: 3.3M школьников в Казахстане × 500 тг/мес = 19.8B тг/год (~$44M)
- **SAM**: 800K учеников 7-12 классов × 500 тг/мес = 4.8B тг/год (~$10M)
- **SOM** (5% за 3 года): 40K платящих пользователей = 240M тг/год (~$500K)
