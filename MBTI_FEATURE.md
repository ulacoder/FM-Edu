# MBTI Профиль - Документация

## Описание
Добавлена функция MBTI профилирования для персонализации обучения студентов. AI учитывает тип личности при генерации объяснений и рекомендаций.

## Что реализовано

### 1. Модель данных
- **MBTIType**: 16 типов личности (INTJ, INFP, ESTP и т.д.)
- **MBTIProfile**: содержит тип, описание, стиль обучения, сильные стороны и сложности
- Добавлено поле `mbtiProfile` в интерфейс `Student`

### 2. Backend API
**Endpoint**: `/api/student/mbti`

**POST** - Сохранение MBTI профиля
```json
{
  "studentId": "string",
  "mbtiType": "INTJ" // один из 16 типов
}
```

Ответ:
- Генерирует персонализированный профиль через Qwen AI
- Сохраняет в `data/students.json`
- Возвращает полный профиль с описанием, стилем обучения, сильными сторонами и сложностями

**GET** - Получение MBTI профиля
```
/api/student/mbti?studentId=xxx
```

### 3. Frontend компоненты

#### `/mbti-profile` - Страница выбора MBTI
- Визуальный селектор всех 16 типов личности
- Группировка по категориям (Аналитики, Дипломаты, Хранители, Исследователи)
- AI-генерация персонализированного профиля
- Отображение сильных сторон и возможных сложностей

#### Компонент `MBTISelector`
- Интерактивный выбор типа
- Emoji и краткие описания каждого типа
- Подтверждение выбора

### 4. Интеграция в AI чат
**Файл**: `/app/api/chat/route.ts`

AI чат (Navi) теперь:
- Получает `studentId` из запроса
- Загружает MBTI профиль студента
- Добавляет контекст в системный промпт:
  - Тип личности
  - Стиль обучения
  - Сильные стороны
  - Возможные сложности
  
Промпт адаптируется: "Адаптируй свои объяснения под тип личности студента"

### 5. Интеграция в UI

#### Дашборд студента
- Кнопка "MBTI профиль" в разделе "Быстрые действия"
- Иконка Brain (🧠)

#### Дашборд учителя
- Новая колонка "MBTI" в таблице студентов
- Отображение типа личности с подсказкой (tooltip) о стиле обучения
- "Не установлен" для студентов без профиля

## Использование

### Для студента:
1. Зайти в дашборд
2. Нажать "MBTI профиль" в быстрых действиях
3. Выбрать свой тип личности
4. Получить персонализированный профиль от AI
5. AI в чате теперь учитывает тип личности

### Для учителя:
- Видеть MBTI типы всех студентов в таблице
- Понимать стиль обучения каждого студента (hover на тип)

## Примеры MBTI типов

### Аналитики
- **INTJ** (Стратег): Аналитический ум, стратегическое мышление
- **INTP** (Логик): Любознательность, абстрактное мышление
- **ENTJ** (Командир): Лидерство, целеустремленность
- **ENTP** (Полемист): Креативность, дебаты

### Дипломаты
- **INFJ** (Активист): Эмпатия, идеализм
- **INFP** (Посредник): Ценности, креативность
- **ENFJ** (Тренер): Харизма, вдохновение
- **ENFP** (Борец): Энтузиазм, воображение

### Хранители
- **ISTJ** (Администратор): Ответственность, порядок
- **ISFJ** (Защитник): Забота, преданность
- **ESTJ** (Менеджер): Организованность, традиции
- **ESFJ** (Консул): Общительность, поддержка

### Исследователи
- **ISTP** (Виртуоз): Практические навыки, логика
- **ISFP** (Артист): Эстетика, спонтанность
- **ESTP** (Предприниматель): Энергичность, действие
- **ESFP** (Развлекатель): Энтузиазм, радость жизни
