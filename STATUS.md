## 📊 Технические детали

### Стек:
- **Frontend/Backend**: Next.js 14 (TypeScript + Tailwind CSS)
- **AI**: Qwen 3.5 Flash (Alibaba Cloud)
- **База данных**: JSON (легко мигрируется на PostgreSQL/Supabase)
- **Авторизация**: JWT + bcrypt

### Данные:
- **57 тем** по программе МОН РК
- **7 предметов**: математика, физика, информатика, химия, биология, экономика, английский
- **Классы**: 7-12
- **Разбивка**: по четвертям
